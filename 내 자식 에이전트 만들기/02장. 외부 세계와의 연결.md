이번 장에서는 **에이전트가 세상과 상호작용하는 방법**을 배워봅시다. <br>
LangGraph에서는 LLM이 단순히 “대화만 하는 존재”를 넘어,
**툴(tool)** 을 통해 외부 시스템(API, DB, 파일 등)에 접근하고,
**메모리(memory)** 를 통해 대화의 맥락을 이어가며,
**미들웨어**로 대화 흐름을 효율적으로 관리할 수 있습니다.

### 🌐 왜 ‘외부 세계와의 연결’이 필요할까요?

에이전트가 사용자의 질문에 답만 한다면, 매번 새로 시작해야 합니다.
하지만 툴과 메모리를 활용하면 이렇게 달라집니다 👇

| 기능 | 역할 |
|------|------|
| 🔧 툴 (Tool) | AI가 외부 시스템과 통신할 수 있는 인터페이스 |
| 🧠 런타임 (ToolRuntime) | 실행 도중 상태(State), 컨텍스트(Context), 저장소(Store)에 접근 |
| 💾 체크포인트 (Checkpoint) | 대화의 흐름과 상태를 안전하게 저장·복원 |
| ✂️ 미들웨어 (Middleware) | 대화 길이를 조정하거나 불필요한 메시지를 정리 |


## 학습 목표

이번 장에서는 AI가 세상과 소통하는 다섯 가지 기술을 실습을 통해 익힙니다.  
이 흐름은 LangChain/LangGraph v1 공식 문서에서 설명하는 **툴·체크포인트·메모리·미들웨어** 구조와 같은 방향을 따르며, 뒤에서 볼 `create_agent` / `StateGraph` 예제의 기반이 됩니다.

**1. 툴로 아이템 장착하기** <br>
     : @tool로 툴을 정의하고, 모델이 호출 가능한 함수 인터페이스 설계
     
**2. 툴 스키마 설계하기** <br>
     : 모델이 툴을 오용하지 않도록 타입·필수값·설명 문구를 최적화하는 방법
     
**3. ToolRuntime 실전 연습** <br>
     : 실행 중 상태(state)·컨텍스트(context)·스토어(store)에 접근하고 업데이트하기
     
**4. 단기 메모리와 체크포인트** <br>
     : 대화 흐름을 저장하고, 중단된 세션을 다시 이어가는 구조 이해
     
**5. 대화 길이를 관리하는 방법**<br>
     : 긴 대화에서 메시지를 잘라내거나 요약하는 미들웨어 패턴 배우기
  
따라서 이번 장에서는 “AI가 외부 세계와 어떻게 협력하고 기억을 유지하는가”를 단계별로 배울 것입니다!

## 실습 환경 설정

### 필수 요구사항
- **Python 3.11 이상** (권장: 3.11+)
- **LangGraph 라이브러리**: `pip install langgraph`
- **OpenAI API**: GPT-4o 모델 사용
- **LangChain Core**: 메시지 타입 지원

### 설치 명령어
```bash
# 핵심 라이브러리 (LangChain/LangGraph v1 기준)
pip install -U langchain langgraph langchain-openai python-dotenv

# 개발 환경 및 시각화
pip install -U jupyter ipython graphviz

# (선택) 데이터베이스 체크포인트
pip install -U langgraph-checkpoint-postgres
```

### 환경 변수 설정
```bash
# .env 파일 생성
echo "OPENAI_API_KEY=your_api_key_here" > .env
```

### 설치 확인
```python
import langgraph, langchain_core
print("LangGraph 버전:", langgraph.__version__)
print("✅ 환경 준비 완료!")
```
