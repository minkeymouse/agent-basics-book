## 06-01. 목표설정

심층 리서치의 첫 번째 단계는 명확한 목표 설정입니다. 사용자의 요청을 분석하여 구체적인 리서치 목표를 정의하고, 효율적인 조사 계획을 수립하는 방법을 학습합니다.

### 학습 목표
- **요청 분석**: 사용자의 리서치 요청을 정확히 파악
- **목표 정의**: 구체적이고 측정 가능한 리서치 목표 설정
- **계획 수립**: 체계적인 조사 계획 및 소스 선정
- **범위 설정**: 리서치 범위와 제약사항 정의

## 요청 분석

### 1. 사용자 요청 파악
사용자의 리서치 요청을 분석하여 핵심 정보를 추출합니다:

```python
from typing import TypedDict, List, Optional
from pydantic import BaseModel

class ResearchRequest(BaseModel):
    topic: str
    scope: str
    depth: str  # "개요", "상세", "심층"
    target_audience: str
    output_format: str
    deadline: Optional[str] = None
    specific_questions: List[str] = []

def analyze_user_request(user_input: str) -> ResearchRequest:
    """사용자 요청 분석"""
    # LLM을 사용하여 요청 분석
    analysis_prompt = f"""
    다음 사용자 요청을 분석하여 리서치 요청 정보를 추출하세요:
    
    사용자 요청: {user_input}
    
    추출할 정보:
    - 주제 (topic)
    - 범위 (scope)
    - 깊이 (depth)
    - 대상 독자 (target_audience)
    - 출력 형식 (output_format)
    - 마감일 (deadline)
    - 구체적인 질문들 (specific_questions)
    """
    
    # 실제로는 LLM을 사용하여 분석
    return ResearchRequest(
        topic="인공지능의 미래",
        scope="기술적 발전과 사회적 영향",
        depth="심층",
        target_audience="일반인",
        output_format="보고서",
        specific_questions=["기술 발전 방향", "사회적 영향", "윤리적 고려사항"]
    )
```

### 2. 요청 검증 및 보완
분석된 요청을 검증하고 필요한 정보를 보완합니다:

```python
def validate_and_complement_request(request: ResearchRequest) -> ResearchRequest:
    """요청 검증 및 보완"""
    # 누락된 정보 확인 및 보완
    if not request.specific_questions:
        request.specific_questions = generate_default_questions(request.topic)
    
    if not request.target_audience:
        request.target_audience = "일반인"
    
    if not request.output_format:
        request.output_format = "보고서"
    
    return request

def generate_default_questions(topic: str) -> List[str]:
    """기본 질문 생성"""
    return [
        f"{topic}의 정의와 개념",
        f"{topic}의 현재 상황",
        f"{topic}의 주요 특징",
        f"{topic}의 장단점",
        f"{topic}의 미래 전망"
    ]
```

## 목표 정의

### 1. 리서치 목표 설정
명확하고 측정 가능한 리서치 목표를 설정합니다:

```python
class ResearchGoal(BaseModel):
    primary_objective: str
    secondary_objectives: List[str]
    success_criteria: List[str]
    deliverables: List[str]
    timeline: str

def define_research_goals(request: ResearchRequest) -> ResearchGoal:
    """리서치 목표 정의"""
    primary_objective = f"{request.topic}에 대한 {request.depth} 분석"
    
    secondary_objectives = [
        f"{request.topic}의 현재 상황 파악",
        f"{request.topic}의 주요 이슈 분석",
        f"{request.topic}의 미래 전망 제시"
    ]
    
    success_criteria = [
        "신뢰할 수 있는 소스에서 정보 수집",
        "다양한 관점에서 분석",
        "구체적이고 실용적인 결론 제시"
    ]
    
    deliverables = [
        "종합 분석 보고서",
        "주요 발견사항 요약",
        "추가 조사 권장사항"
    ]
    
    return ResearchGoal(
        primary_objective=primary_objective,
        secondary_objectives=secondary_objectives,
        success_criteria=success_criteria,
        deliverables=deliverables,
        timeline="1주일"
    )
```

### 2. 조사 질문 개발
구체적인 조사 질문을 개발합니다:

```python
def develop_research_questions(request: ResearchRequest, goals: ResearchGoal) -> List[str]:
    """조사 질문 개발"""
    base_questions = request.specific_questions
    
    # 목표에 따른 추가 질문 생성
    additional_questions = []
    
    for objective in goals.secondary_objectives:
        if "현재 상황" in objective:
            additional_questions.append(f"{request.topic}의 현재 시장 규모는?")
            additional_questions.append(f"{request.topic}의 주요 플레이어는?")
        elif "이슈" in objective:
            additional_questions.append(f"{request.topic}의 주요 도전과제는?")
            additional_questions.append(f"{request.topic}의 해결 방안은?")
        elif "미래" in objective:
            additional_questions.append(f"{request.topic}의 향후 5년 전망은?")
            additional_questions.append(f"{request.topic}의 발전 방향은?")
    
    return base_questions + additional_questions
```

### 2. 소스 우선순위 설정
정보 소스의 우선순위를 설정합니다:

```python
def prioritize_sources(plan: ResearchPlan, request: ResearchRequest) -> dict:
    """소스 우선순위 설정"""
    source_priority = {}
    
    for source in plan.data_sources:
        if "학술" in source or "논문" in source:
            priority = 1  # 최고 우선순위
        elif "정부" in source or "공공" in source:
            priority = 2
        elif "업계" in source or "보고서" in source:
            priority = 3
        elif "뉴스" in source or "미디어" in source:
            priority = 4
        else:
            priority = 5
        
        source_priority[source] = priority
    
    return source_priority
```

## 범위 설정

### 1. 리서치 범위 정의
리서치의 범위와 제약사항을 명확히 정의합니다:

```python
class ResearchScope(BaseModel):
    included_topics: List[str]
    excluded_topics: List[str]
    geographic_scope: str
    time_scope: str
    depth_level: str
    constraints: List[str]

def define_research_scope(request: ResearchRequest) -> ResearchScope:
    """리서치 범위 정의"""
    included_topics = [request.topic]
    
    # 관련 주제 추가
    if "인공지능" in request.topic:
        included_topics.extend(["머신러닝", "딥러닝", "자연어처리"])
    elif "블록체인" in request.topic:
        included_topics.extend(["암호화폐", "스마트 컨트랙트", "DeFi"])
    
    excluded_topics = [
        "과도하게 기술적인 세부사항",
        "법적 조언",
        "투자 권고"
    ]
    
    geographic_scope = "글로벌 (한국 중심)"
    time_scope = "최근 5년 (향후 5년 전망 포함)"
    depth_level = request.depth
    
    constraints = [
        "신뢰할 수 있는 소스만 사용",
        "객관적이고 균형잡힌 관점 유지",
        "일반인이 이해할 수 있는 수준으로 설명"
    ]
    
    return ResearchScope(
        included_topics=included_topics,
        excluded_topics=excluded_topics,
        geographic_scope=geographic_scope,
        time_scope=time_scope,
        depth_level=depth_level,
        constraints=constraints
    )
```
