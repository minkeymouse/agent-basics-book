## 06-02. 조사

목표와 계획이 설정되면 실제 조사 단계로 진행합니다. 다양한 소스에서 정보를 수집하고, 신뢰성을 검증하며, 체계적으로 분석하는 방법을 학습합니다.

### 학습 목표
- **다중 소스 조사**: 웹, 학술논문, 뉴스 등 다양한 소스에서 정보 수집
- **정보 검증**: 수집된 정보의 신뢰성과 정확성 검증
- **데이터 분석**: 수집된 정보를 체계적으로 분석하고 분류
- **통찰 도출**: 단순한 정보 나열을 넘어서 인사이트 제공

## 다중 소스 조사

### 1. 웹 검색
웹에서 최신 정보를 수집합니다:

```python
import requests
from typing import List, Dict

class WebSearchResult:
    def __init__(self, title: str, url: str, snippet: str, relevance_score: float):
        self.title = title
        self.url = url
        self.snippet = snippet
        self.relevance_score = relevance_score

def search_web(query: str, num_results: int = 10) -> List[WebSearchResult]:
    """웹 검색 수행"""
    # 실제로는 검색 API (Google, Bing 등) 사용
    results = []
    
    # 예시 결과
    results.append(WebSearchResult(
        title=f"{query} 관련 최신 뉴스",
        url="https://example.com/news",
        snippet=f"{query}에 대한 최신 동향과 분석...",
        relevance_score=0.9
    ))
    
    return results

def search_multiple_queries(queries: List[str]) -> Dict[str, List[WebSearchResult]]:
    """여러 쿼리로 병렬 검색"""
    search_results = {}
    
    for query in queries:
        results = search_web(query)
        search_results[query] = results
    
    return search_results
```

## 정보 검증

### 1. 신뢰성 평가
수집된 정보의 신뢰성을 평가합니다:

```python
class SourceCredibility:
    def __init__(self, source: str, credibility_score: float, 
                 domain_authority: str, bias_level: str):
        self.source = source
        self.credibility_score = credibility_score
        self.domain_authority = domain_authority
        self.bias_level = bias_level

def evaluate_source_credibility(source: str) -> SourceCredibility:
    """소스 신뢰성 평가"""
    # 신뢰할 수 있는 소스 목록
    trusted_sources = {
        "nature.com": {"score": 0.95, "authority": "high", "bias": "neutral"},
        "science.org": {"score": 0.93, "authority": "high", "bias": "neutral"},
        "reuters.com": {"score": 0.88, "authority": "high", "bias": "neutral"},
        "bbc.com": {"score": 0.85, "authority": "high", "bias": "neutral"}
    }
    
    domain = source.split("//")[-1].split("/")[0]
    source_info = trusted_sources.get(domain, 
                                    {"score": 0.5, "authority": "unknown", "bias": "unknown"})
    
    return SourceCredibility(
        source=source,
        credibility_score=source_info["score"],
        domain_authority=source_info["authority"],
        bias_level=source_info["bias"]
    )

def filter_by_credibility(results: List, min_credibility: float = 0.7) -> List:
    """신뢰성 기준으로 필터링"""
    filtered_results = []
    
    for result in results:
        credibility = evaluate_source_credibility(result.url)
        if credibility.credibility_score >= min_credibility:
            filtered_results.append(result)
    
    return filtered_results
```

### 2. 정보 일관성 검증
여러 소스의 정보 일관성을 검증합니다:

```python
def check_information_consistency(sources: List[Dict]) -> Dict:
    """정보 일관성 검증"""
    consistency_report = {
        "consistent_facts": [],
        "conflicting_facts": [],
        "unique_facts": [],
        "consistency_score": 0.0
    }
    
    # 간단한 일관성 검사 예시
    all_facts = []
    for source in sources:
        all_facts.extend(source.get("facts", []))
    
    # 중복 사실 확인
    fact_counts = {}
    for fact in all_facts:
        fact_counts[fact] = fact_counts.get(fact, 0) + 1
    
    for fact, count in fact_counts.items():
        if count > 1:
            consistency_report["consistent_facts"].append(fact)
        else:
            consistency_report["unique_facts"].append(fact)
    
    # 일관성 점수 계산
    total_facts = len(all_facts)
    consistent_facts = len(consistency_report["consistent_facts"])
    consistency_report["consistency_score"] = consistent_facts / total_facts if total_facts > 0 else 0
    
    return consistency_report
```

## 데이터 분석

### 1. 정보 분류 및 구조화

```python
class InformationCategory:
    def __init__(self, category: str, information: List[str], 
                 confidence: float, sources: List[str]):
        self.category = category
        self.information = information
        self.confidence = confidence
        self.sources = sources

def categorize_information(search_results: Dict) -> List[InformationCategory]:
    """정보 분류"""
    categories = []
    
    # 기본 카테고리
    basic_categories = [
        "정의 및 개념",
        "현재 상황",
        "주요 특징",
        "장단점",
        "미래 전망",
        "관련 기술",
        "시장 동향"
    ]
    
    for category in basic_categories:
        category_info = []
        sources = []
        
        # 각 소스에서 해당 카테고리 정보 추출
        for source_type, results in search_results.items():
            for result in results:
                if category.lower() in result.title.lower() or category.lower() in result.snippet.lower():
                    category_info.append(result.snippet)
                    sources.append(result.url)
        
        if category_info:
            categories.append(InformationCategory(
                category=category,
                information=category_info,
                confidence=0.8,
                sources=sources
            ))
    
    return categories
```

### 2. 트렌드 분석
시간에 따른 변화와 트렌드를 분석합니다:

```python
def analyze_trends(articles: List[NewsArticle], papers: List[AcademicPaper]) -> Dict:
    """트렌드 분석"""
    trend_analysis = {
        "temporal_trends": {},
        "sentiment_trends": {},
        "topic_evolution": {},
        "key_events": []
    }
    
    # 시간별 트렌드 분석
    years = {}
    for paper in papers:
        year = paper.year
        if year not in years:
            years[year] = 0
        years[year] += 1
    
    trend_analysis["temporal_trends"] = years
    
    # 감정 트렌드 분석
    sentiments = {}
    for article in articles:
        sentiment = article.sentiment
        if sentiment not in sentiments:
            sentiments[sentiment] = 0
        sentiments[sentiment] += 1
    
    trend_analysis["sentiment_trends"] = sentiments
    
    return trend_analysis
```

## 통찰 도출

### 1. 패턴 인식
수집된 정보에서 패턴을 찾아 통찰을 도출합니다:

```python
def identify_patterns(categories: List[InformationCategory]) -> List[str]:
    """패턴 인식 및 통찰 도출"""
    insights = []
    
    # 반복되는 키워드 분석
    all_text = ""
    for category in categories:
        all_text += " ".join(category.information)
    
    # 간단한 키워드 빈도 분석
    keywords = {}
    words = all_text.lower().split()
    
    for word in words:
        if len(word) > 3:  # 3글자 이상 단어만
            keywords[word] = keywords.get(word, 0) + 1
    
    # 상위 키워드 기반 통찰 생성
    top_keywords = sorted(keywords.items(), key=lambda x: x[1], reverse=True)[:10]
    
    for keyword, count in top_keywords:
        if count > 5:  # 5번 이상 언급된 키워드
            insights.append(f"'{keyword}'가 {count}번 언급되어 핵심 개념임")
    
    return insights
```

### 2. 갭 분석
현재 정보의 부족한 부분을 식별합니다:

```python
def identify_information_gaps(categories: List[InformationCategory], 
                            research_questions: List[str]) -> List[str]:
    """정보 갭 식별"""
    gaps = []
    
    # 연구 질문과 수집된 정보 비교
    covered_topics = [cat.category for cat in categories]
    
    for question in research_questions:
        question_covered = False
        for topic in covered_topics:
            if any(word in question.lower() for word in topic.lower().split()):
                question_covered = True
                break
        
        if not question_covered:
            gaps.append(f"'{question}'에 대한 정보 부족")
    
    return gaps
```
