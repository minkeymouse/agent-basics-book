이번 섹션에서는 LangGraph Studio를 설정하고 실행하는 방법을 배워봅니다. LangGraph Studio는 에이전트를 시각적으로 개발하고 테스트할 수 있는 개발 환경입니다. Studio는 선택사항입니다. Python 스크립트로 직접 실행해도 되지만, 처음에는 Studio를 사용하는 것을 권장합니다. Studio를 사용하면 그래프 구조를 시각적으로 확인할 수 있고, 에이전트와 직접 대화하며, 실행 과정을 실시간으로 모니터링할 수 있습니다.

LangGraph Studio는 LangGraph 에이전트를 개발하고 테스트하기 위한 시각적 개발 환경입니다. 브라우저에서 그래프 구조를 시각적으로 확인하고, 에이전트와 직접 대화하며, 실행 과정을 실시간으로 모니터링할 수 있습니다. 노드와 엣지를 시각적으로 확인하고 편집할 수 있고, 브라우저에서 직접 에이전트와 대화할 수 있으며, 실행 흐름과 상태 변화를 실시간으로 모니터링할 수 있습니다. Studio에서 자체적으로 메모리 관리도 하며, 에이전트 실행 과정을 실시간으로 확인할 수 있습니다.

먼저 프로젝트 디렉토리를 생성하고 필요한 파일들을 준비합니다:

```bash
# 프로젝트 디렉토리 생성
mkdir research-agent
cd research-agent

# 필요한 디렉토리 생성
mkdir graphs
```

프로젝트 구조는 다음과 같습니다:

```
research-agent/
├── graphs/
│   └── research_agent.py    # 자료조사 에이전트 구현 (agent 변수로 export)
├── langgraph.json           # Studio 설정 파일 (필수)
├── .env                     # 환경 변수 (API 키)
└── requirements.txt         # 의존성 목록
```

`graphs` 폴더는 그래프 정의 파일을 저장하는 디렉토리입니다. 여러 그래프를 만들 수 있습니다. `graphs/research_agent.py`는 자료조사 에이전트를 정의하는 파일인데, 이 파일에서 `agent` 변수로 에이전트를 export해야 합니다. `langgraph.json`은 LangGraph Dev/Studio가 그래프를 찾기 위한 설정 파일로, 반드시 프로젝트 루트에 있어야 합니다. `.env`는 API 키 등 환경 변수를 저장하는 파일인데, Git에 커밋하지 않도록 주의하세요. `requirements.txt`는 Python 패키지 의존성을 정의하는 파일입니다.

Studio가 그래프를 인식할 수 있도록 `langgraph.json` 파일을 프로젝트 루트에 생성합니다:

```json
{
    "graphs": {
        "research_agent": "./graphs/research_agent.py:agent"
    },
    "env": "./.env",
    "python_version": "3.11",
    "dependencies": [
        "."
    ]
}
```

`graphs`는 그래프 정의를 담는 객체로, 여러 그래프를 정의할 수 있습니다. `research_agent`는 Studio에서 표시될 그래프 이름입니다. 이 이름으로 Studio에서 그래프를 선택할 수 있습니다. `./graphs/research_agent.py:agent`는 그래프가 정의된 파일 경로와 변수명입니다. `./graphs/research_agent.py`는 그래프가 정의된 Python 파일 경로이고, `:agent`는 해당 파일에서 export되는 그래프 변수명입니다. 예를들어 `agent = create_agent(...)`와 같이 정의하면 됩니다. `env`는 환경 변수 파일 경로로, API 키 등을 여기에 설정합니다. `python_version`은 사용할 Python 버전이고, `dependencies`는 의존성 목록입니다. `"."`는 현재 디렉토리를 의미하며, `requirements.txt`나 `pyproject.toml`의 의존성을 사용합니다.

`.env` 파일에 필요한 API 키를 설정합니다:

```bash
# .env 파일
OPENAI_API_KEY=your_openai_api_key_here
TAVILY_API_KEY=your_tavily_api_key_here
```

OpenAI API 키는 OpenAI 웹사이트에서 발급받을 수 있고, Tavily API 키는 Tavily 웹사이트에서 무료로 발급 가능합니다.

필요한 라이브러리를 `requirements.txt`에 추가합니다:

```txt
langchain>=0.3.0
langgraph>=0.2.0
langchain-openai>=0.2.0
langchain-community>=0.3.0
python-dotenv>=1.0.0
reportlab>=4.0.0
langgraph-cli[inmem]>=0.2.0
```

의존성을 설치하려면 `pip install -r requirements.txt`를 실행하거나, 개별적으로 `pip install langchain langgraph langchain-openai langchain-community python-dotenv reportlab "langgraph-cli[inmem]"`을 실행합니다. `langgraph-cli[inmem]`은 Studio를 실행하기 위해 필요하며, `[inmem]`은 메모리 기반 체크포인터를 사용하기 위한 옵션입니다.

이제 Studio를 실행해봅시다. 먼저 LangGraph CLI를 설치해야 합니다:

```bash
# Python 환경에서 설치
pip install "langgraph-cli[inmem]"
```

또는 npm을 사용하는 경우 `npm install -g @langchain/langgraph-cli`를 실행할 수 있습니다.

현재 디렉토리가 `research-agent/`인지 확인한 후 다음 명령어를 실행합니다:

```bash
# LangGraph Dev 실행 (Studio와 연결)
langgraph dev
```

`langgraph dev`를 실행하면 터미널에 "LangGraph Dev Server is running at http://localhost:2024"와 "Studio is available at https://smith.langchain.com" 메시지가 표시됩니다.

브라우저에서 LangSmith Studio에 접속하고, Studio에서 로컬 서버(`http://localhost:2024`)에 연결합니다. 그래프 목록에서 `research_agent`를 선택합니다. `langgraph dev`는 로컬 개발 서버를 실행하고, Studio는 LangSmith 웹사이트에서 이 서버에 연결하여 에이전트를 시각화하고 테스트합니다.

Studio 인터페이스는 그래프 시각화, 채팅 인터페이스, 상태 모니터, 로그 뷰어, HITL 처리 기능으로 구성되어 있습니다. 그래프 시각화에서는 노드와 엣지가 시각적으로 표시되고, 채팅 인터페이스에서는 에이전트와 직접 대화할 수 있습니다. 상태 모니터에서는 실행 중 상태 변화를 실시간으로 확인할 수 있고, 로그 뷰어에서는 실행 과정과 에러 메시지를 확인할 수 있습니다. HITL 처리에서는 중단된 작업을 승인, 수정, 거절할 수 있습니다.

Studio에서 그래프의 구조를 시각적으로 확인할 수 있습니다. 자료조사 에이전트의 경우 START에서 model로 시작하여 tools를 거쳐 다시 model로 돌아오는 흐름을 확인할 수 있습니다. Studio에서 각 노드의 입력/출력 상태, 툴 호출 과정, 상태 변화의 실시간 모니터링, 에러 발생 지점과 디버깅 정보, HITL 중단 지점과 승인 대기 상태를 확인할 수 있습니다.

Studio의 채팅 인터페이스에서 에이전트와 직접 대화할 수 있습니다. 하단의 입력창에 자료조사 요청을 입력하면, 예를들어 "요즘 가장 주목받는 영화 다섯개를 찾아서 보고서로 정리해줘"라고 입력하면, 에이전트의 응답을 실시간으로 확인할 수 있고, 우측 패널에서 상태 변화를 확인할 수 있으며, PDF 생성 전에 Studio에서 승인, 수정, 거절을 선택할 수 있습니다.

Studio는 강력한 디버깅 기능을 제공합니다. 각 노드의 실행 순서와 결과를 확인할 수 있고, 메시지와 도구 호출 결과의 변화를 추적할 수 있으며, 발생한 에러의 원인과 위치를 파악할 수 있습니다. 또한 에이전트의 실행 과정을 단계별로 확인할 수 있습니다.

Studio에서 에이전트를 실행하면, PDF 생성 도구 호출 시 자동으로 중단됩니다. Studio 인터페이스에서 승인 대기 중인 작업을 확인하고, 도구 인자를 확인 및 수정하며, 승인, 수정, 거절을 선택하고, 실행을 재개할 수 있습니다.

Studio를 사용하면 복잡한 그래프 구조를 직관적으로 이해할 수 있고, 코드 수정 후 즉시 결과를 확인할 수 있으며, 빠른 피드백을 통한 효율적인 개발이 가능합니다. 실행 과정을 실시간으로 추적할 수 있고, 복잡한 상태 변화를 시각적으로 확인할 수 있으며, 문제 발생 지점을 정확히 파악할 수 있습니다. 팀원들과 그래프 구조를 공유할 수 있고, 시각적 그래프를 통한 자동 문서화가 가능하며, 그래프 변경 사항을 추적할 수 있습니다.

Studio와 Python 스크립트를 비교하면, Studio는 그래프 구조와 실행 흐름을 시각적으로 확인할 수 있고, 코드 수정 없이 즉시 테스트가 가능하며, 브라우저에서 직접 승인, 수정, 거절이 가능하고, 실행 중 상태 변화를 실시간으로 확인할 수 있습니다. Python 스크립트는 코드로 실행 흐름을 완전히 제어할 수 있고, 스크립트로 자동 실행이 가능하며, 다른 시스템과 쉽게 통합할 수 있습니다. 처음에는 Studio를 사용하여 에이전트를 테스트하고, 안정화된 후 Python 스크립트로 실행하는 것이 좋습니다.

이제 LangGraph Studio 환경을 설정하고 실행하는 방법을 이해했습니다. 다음 섹션에서는 자료조사 에이전트의 개념을 자세히 살펴보고, 그 다음 섹션에서 실제로 에이전트를 만들어보겠습니다.
