자료조사 에이전트는 사용자가 요청한 주제에 대해 인터넷을 검색하고, 수집한 정보를 바탕으로 체계적인 보고서를 작성해주는 AI 에이전트입니다. 일반적인 검색 엔진과 달리, 자료조사 에이전트는 여러 검색 결과를 종합하여 분석하고, 사용자가 원하는 형식으로 보고서를 작성합니다. 3장에서 배운 Human-in-the-Loop을 통해 PDF 생성 전에 사용자 승인을 받고, 최종적으로 PDF 형태의 보고서를 생성합니다.

일반적으로 자료조사를 할 때는 검색 엔진에서 여러 키워드로 검색하고, 검색 결과를 하나하나 클릭하며 읽고, 중요한 정보를 수동으로 정리한 다음, 보고서 형식에 맞춰 작성합니다. 이 과정은 시간이 오래 걸리고, 누락되는 정보가 있을 수 있습니다.

자료조사 에이전트를 사용하면 검색부터 보고서 작성까지 자동으로 처리할 수 있고, 여러 검색 결과를 종합하여 더 정확한 정보를 제공할 수 있으며, 항상 동일한 형식의 보고서를 생성할 수 있고, 수동 작업 시간을 크게 단축할 수 있습니다.

자료조사 에이전트는 LangChain/LangGraph v1 관점에서 보면 “검색 툴 + 보고서 생성 툴 + HITL 미들웨어”가 결합된 하나의 그래프입니다. 먼저 사용자가 자연어로 자료조사 요청을 합니다. 예를들어 "요즘 가장 주목받는 영화 다섯개를 찾아서 보고서로 정리해줘"라고 요청하면, 에이전트는 Tavily Search를 활용해 관련 정보를 검색합니다. 검색 쿼리는 "2024년 주목받는 영화", "최신 영화 순위", "인기 영화" 등이 될 수 있고, 검색 결과는 영화 정보가 포함된 웹 페이지들입니다.

수집한 정보를 바탕으로 체계적인 보고서를 작성합니다. 각 영화의 제목, 개봉일, 주요 내용 등을 정리합니다. 에이전트가 PDF를 생성하기 전에, HITL 미들웨어가 실행을 중단하고 사용자의 승인을 기다립니다. 3장에서 배운 내용입니다. 에이전트 실행이 중단되면 승인이 필요한 작업이 표시되고, 도구는 `generate_pdf_report`이며, 인자로 보고서 제목, 내용, 출력 경로가 표시됩니다. 사용자가 승인하면 작성된 보고서를 PDF 파일로 변환합니다.

자료조사 에이전트는 다양한 활용 사례가 있습니다. 시장 조사 보고서의 경우, "최근 전기차 시장 동향에 대해 조사해줘"라고 요청하면 에이전트는 전기차 시장 규모, 성장률, 주요 기업 정보를 검색하고, 시장 동향을 분석하여 보고서를 작성하며, PDF 형태로 제공합니다.

여행 계획서의 경우, "제주도 여행을 하려고 하는데 여행 계획을 짜줘"라고 요청하면 에이전트는 제주도 관광지, 맛집, 숙소 정보를 검색하고, 일정별 여행 계획을 작성하며, PDF 형태의 여행 계획서를 제공합니다.

뉴스 요약 보고서의 경우, "최근 미국의 정치, 경제 동향에 대해 정리해줘"라고 요청하면 에이전트는 최신 뉴스 기사를 검색하고, 정치와 경제 동향을 분류하여 정리하며, 종합 보고서를 작성합니다.

자료조사 에이전트의 핵심 기능은 웹 검색, Human-in-the-Loop, 보고서 생성입니다. 웹 검색은 Tavily Search를 통해 최신 정보를 실시간으로 검색하고, 여러 키워드로 검색하여 포괄적인 정보를 수집하며, 제목, URL, 요약, 원문을 구조화된 형태로 제공합니다.

Human-in-the-Loop은 PDF 생성 전에 사용자 승인을 받아 안전성을 보장합니다. 3장에서 배운 내용입니다. 잘못된 형식이나 내용을 사전에 방지하고, 사용자가 보고서 내용을 확인하고 수정할 수 있어 만족도가 향상됩니다.

보고서 생성은 일관된 형식으로 보고서를 작성하고, 여러 검색 결과를 종합하여 분석하며, 최종 결과를 PDF 파일로 제공합니다.

이번 장에서 만드는 자료조사 에이전트는 1장부터 3장까지 배운 모든 내용을 활용합니다. 1장에서는 `create_agent`를 통한 에이전트 생성과 여러 툴을 하나의 에이전트에 통합하는 방법을 배웠습니다. 2장에서는 `@tool` 데코레이터를 활용한 커스텀 툴 생성, 타입 힌트와 docstring을 통한 자동 스키마 생성, `InMemorySaver`를 통한 대화 세션 관리를 배웠습니다. 3장에서는 `HumanInTheLoopMiddleware`를 통한 사용자 승인, `stream_mode="updates"`를 통한 실행 과정 추적, 위험한 작업에 대한 사용자 승인을 배웠습니다.

이제 자료조사 에이전트가 무엇인지 이해했습니다. 다음 섹션에서는 실제로 자료조사 에이전트를 단계별로 만들어보겠습니다.
