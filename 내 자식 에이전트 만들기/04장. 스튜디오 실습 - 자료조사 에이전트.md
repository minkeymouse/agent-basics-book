## 🎯 자료조사 에이전트란?

**자료조사 에이전트**는 사용자가 요청한 주제에 대해 인터넷을 검색하고, 수집한 정보를 바탕으로 체계적인 보고서를 작성해주는 에이전트입니다. 

예를들어 다음과 같은 요청을 처리할 수 있습니다:

- "요즘 가장 주목받는 영화 다섯개를 찾아서 보고서로 정리해줘"
- "제주도 여행을 하려고 하는데 여행 계획을 짜줘"
- "최근 미국의 정치, 경제 동향에 대해 정리해줘"

이런 요청을 받으면 에이전트는:
1. Tavily Search를 활용해 관련 정보를 검색합니다
2. 수집한 정보를 바탕으로 보고서를 작성합니다
3. PDF 생성 전에 사용자 승인을 받습니다 (Human-in-the-Loop, 3장)
4. 최종적으로 PDF 형태의 보고서를 생성합니다

## 실습 환경 설정

### 필수 요구사항
- **Python 3.11 이상**
- **LangChain 및 LangGraph**: `pip install langchain langgraph langchain-openai langchain-community`
- **Tavily API 키**: [Tavily 웹사이트](https://tavily.com)에서 무료 API 키 발급
- **OpenAI API 키**: ChatOpenAI 모델 사용을 위해 필요
- **PDF 생성 라이브러리**: `pip install reportlab` 또는 `pip install fpdf2`

### 설치 명령어
```bash
# 핵심 라이브러리
pip install -U langchain langgraph langchain-openai langchain-community

# PDF 생성 라이브러리 (선택: reportlab 또는 fpdf2)
pip install reportlab

# 환경 변수 관리를 위한 라이브러리
pip install python-dotenv
```

### 환경 변수 설정
```bash
# .env 파일 생성
echo "OPENAI_API_KEY=your_openai_api_key_here" > .env
echo "TAVILY_API_KEY=your_tavily_api_key_here" >> .env
```

### 설치 확인
```python
import langchain
import langgraph
print(f"LangChain 버전: {langchain.__version__}")
print(f"LangGraph 버전: {langgraph.__version__}")
print("✅ 환경 준비 완료!")
```

## 핵심 개념

### LangGraph Studio
- **시각적 개발**: 그래프 구조를 시각적으로 확인하고 테스트
- **실시간 디버깅**: 에이전트 실행 과정을 실시간으로 모니터링
- **HITL 처리**: 브라우저에서 직접 승인/수정/거절 가능

### Tavily Search
- **웹 검색 API**: 실시간 웹 검색 결과를 제공하는 서비스
- **LangChain 통합**: `TavilySearchResults` 툴로 간편하게 사용 가능
- **검색 결과**: 제목, URL, 요약, 원문 내용 등을 구조화된 형태로 제공

### Human-in-the-Loop (HITL)
- **사용자 승인**: 중요한 작업(PDF 생성) 전에 사용자의 확인을 받는 메커니즘 (3장)
- **안전성**: 잘못된 작업을 방지하고 사용자 의도에 맞는 결과 보장
- **Studio 지원**: Studio에서 브라우저로 직접 승인/수정/거절 가능

### 커스텀 툴
- **PDF 생성 툴**: 검색 결과를 바탕으로 PDF 보고서를 생성하는 툴
- **@tool 데코레이터**: Python 함수를 LangGraph 툴로 변환
- **Pydantic 스키마**: 툴 입력 구조를 명확히 정의
