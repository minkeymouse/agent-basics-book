이번 섹션에서는 에이전트를 로컬에서 실행하는 방법을 배워봅시다. 초급자도 쉽게 따라할 수 있도록 간단한 방법부터 시작하겠습니다.

이 책에서는 기본적인 에이전트 사용법에 집중합니다. 프로덕션 환경에 배포하는 방법(Docker 등)은 별도의 주제이므로 여기서는 다루지 않습니다.

이제 만든 SQL 에이전트를 실행해보겠습니다. 먼저 앞서 4번 파일에서 만든 SQL 에이전트 코드를 하나의 파일로 정리하겠습니다.

```python
# sql_agent.py
from langchain_community.utilities import SQLDatabase
from langchain_community.agent_toolkits import SQLDatabaseToolkit
from langchain_openai import ChatOpenAI
from langchain_core.messages import SystemMessage, HumanMessage
from langgraph.graph import StateGraph, START, END, MessagesState
from langgraph.prebuilt import ToolNode, tools_condition

# SQLite 데이터베이스 연결
db = SQLDatabase.from_uri("sqlite:///chinook.db")
llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)

# 도구 생성
toolkit = SQLDatabaseToolkit(db=db, llm=llm)
tools = toolkit.get_tools()

# 도구를 LLM에 바인딩
llm_with_tools = llm.bind_tools(tools, parallel_tool_calls=False)

# 시스템 메시지 정의
system_msg = SystemMessage(
    content="""You are a SQL database assistant.
Given a question, you should:
1. List available tables
2. Get schema of relevant tables  
3. Generate and execute a SQL query
4. Return the results in a natural way

IMPORTANT: Only use SELECT queries. Never modify the database."""
)

# Assistant 노드 정의
def assistant(state: MessagesState):
    """ReAct 에이전트의 추론(Reasoning) 단계"""
    return {"messages": [llm_with_tools.invoke([system_msg] + state["messages"])]}

# 그래프 구성
builder = StateGraph(MessagesState)
builder.add_node("assistant", assistant)
builder.add_node("tools", ToolNode(tools))

builder.add_edge(START, "assistant")
builder.add_conditional_edges("assistant", tools_condition)
builder.add_edge("tools", "assistant")
builder.add_edge("assistant", END)

# 그래프 컴파일
sql_agent = builder.compile()
```

이 코드는 4번 파일에서 배운 LangGraph 방식으로 SQL 에이전트를 구성합니다. ReAct 패턴을 사용하여 `assistant → tools → assistant` 루프를 통해 단계별로 문제를 해결합니다.

이제 만든 SQL 에이전트를 실행해보겠습니다.

```python
# 에이전트 실행
result = sql_agent.invoke({
    "messages": [
        HumanMessage(content="데이터베이스에 어떤 테이블들이 있나요?")
    ]
})

print(result["messages"][-1].content)
```

에이전트가 실행되면 내부적으로 다음과 같은 과정을 거칩니다. 먼저 assistant 노드가 사용자 질문을 분석하고 `sql_db_list_tables` 도구를 호출하도록 결정합니다. 다음으로 tools 노드가 도구를 실행하여 테이블 목록을 가져옵니다. assistant 노드가 도구 결과를 받아서 자연스러운 언어로 설명하고, 더 이상 도구 호출이 필요 없으므로 END로 종료합니다. 이렇게 ReAct 루프를 통해 에이전트가 단계별로 문제를 해결합니다.

실행하면 다음과 같은 결과가 나옵니다:

```
데이터베이스에는 다음과 같은 테이블들이 있습니다:
- albums
- artists
- customers
- employees
- genres
- invoice_lines
- invoices
- media_types
- playlists
- playlist_track
- tracks
```

에이전트의 실행 과정을 실시간으로 확인하려면 `stream` 메서드를 사용할 수 있습니다.

```python
# 스트리밍으로 실행
for chunk in sql_agent.stream({
    "messages": [
        HumanMessage(content="가장 많이 팔린 상품 5개를 알려줘")
    ]
}, stream_mode="updates"):
    for step, data in chunk.items():
        print(f"Step: {step}")
        if "messages" in data:
            last_msg = data["messages"][-1]
            if hasattr(last_msg, "tool_calls") and last_msg.tool_calls:
                print(f"도구 호출: {last_msg.tool_calls[0]['name']}")
            elif hasattr(last_msg, "content"):
                print(f"응답: {last_msg.content[:100]}...")
        print("-" * 50)
```

스트리밍을 사용하면 에이전트가 어떤 도구를 호출하는지, 각 단계에서 무엇을 하는지 실시간으로 확인할 수 있습니다. 이는 디버깅과 모니터링에 매우 유용합니다.

에이전트를 정의하는 Python 파일을 작성한 후, `invoke` 메서드로 에이전트를 실행할 수 있습니다. 반환된 메시지에서 결과를 확인하면 됩니다. 다양한 질문에 활용해보고, 다른 데이터베이스와 연결해보며, 에이전트의 응답을 개선해나가면 됩니다.

이제 7장 "에이전트 지식 쌓기"의 모든 내용을 학습했습니다. Store로 지식베이스를 만들고, Retrieval로 정보를 찾고 업데이트하며, SQL 에이전트를 구축하는 방법을 배웠습니다. 이제 배운 내용을 활용하여 자신만의 지식베이스 기반 에이전트를 만들어보세요!
