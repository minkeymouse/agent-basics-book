랭그래프를 실행하기 위해서는 먼저 컴퓨터에 파이썬이 필요합니다. 가능한 한 3.11 이상의 버전을 권장합니다. 명령을 입력하기 위한 터미널(Windows의 PowerShell이나 macOS/Linux의 터미널)이 있어야 하고, Studio 화면을 보기 위해서는 브라우저가 필요합니다.

### 파이썬 설치 확인

가장 먼저 파이썬이 설치되어 있는지 확인합니다. 터미널을 열고 아래 명령을 입력했을 때 버전 숫자가 보인다면 준비가 된 것입니다. 3.11 이상이라면 그대로 진행해도 좋습니다.

```bash
python --version
```

만약 버전이 낮거나 설치되어 있지 않다면, Python 공식 사이트(`https://www.python.org/downloads/`)에서 운영체제에 맞는 최신 설치 프로그램을 내려받아 설치합니다.

### 프로젝트 디렉토리 만들기

이제 작업을 위한 디렉토리를 하나 만들겠습니다. 예시로 `langgraph-basics`라는 이름을 사용합니다. 디렉토리를 만든 뒤 해당 폴더 안으로 이동합니다.

```bash
mkdir langgraph-basics && cd langgraph-basics
```

### 가상환경 생성 및 활성화

서로 다른 프로젝트의 라이브러리가 섞이지 않도록, 프로젝트 전용 가상환경을 만들어 사용합니다. 아래 명령을 실행하면 현재 폴더에 `.venv`라는 이름의 가상환경이 생성됩니다. 이어서 운영체제에 맞는 명령으로 가상환경을 활성화합니다. 프롬프트 앞에 `(venv)`와 비슷한 표기가 보이면 성공입니다.

```bash
python -m venv .venv
```

- **Windows**
  ```bash
  .venv\Scripts\activate
  ```

- **macOS/Linux**
  ```bash
  source .venv/bin/activate
  ```

가상환경이 활성화되지 않는다면, Windows의 경우 실행 정책(ExecutionPolicy)이나 보안 소프트웨어가 명령 실행을 막고 있을 수 있습니다. 잠시 정책을 완화했다가 다시 되돌리면 해결되는 경우가 많습니다.

### 필수 패키지 설치

이제 필요한 라이브러리를 설치합니다. 우선 `pip`를 최신으로 올린 뒤, 랭그래프와 예제에서 사용할 기본 패키지를 설치합니다.

```bash
pip install -U pip
pip install langgraph langchain_openai langchain_core python-dotenv
```

### 설치 확인

설치가 잘 되었는지 간단히 확인해 보겠습니다. 파이썬 셸을 열어 아래 코드를 입력했을 때 에러 없이 버전이 출력되면 준비가 끝난 것입니다.

```python
import langgraph
print("LangGraph 버전:", langgraph.__version__)
```

만약 `ModuleNotFoundError`가 발생한다면 가상환경이 활성화되어 있는지, 설치 명령을 가상환경에서 실행했는지부터 확인하세요.
